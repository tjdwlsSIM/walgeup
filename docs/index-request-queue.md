# 색인 요청 대기열

새 글은 검색엔진이 알아서 찾아주지 않습니다. **아래 항목은 사람이 직접 처리해야
합니다.** 처리한 뒤 체크박스를 `[x]` 로 바꿔 주세요.

- 구글: [Search Console](https://search.google.com/search-console) → URL 검사 → 색인 생성 요청
- 네이버: [서치어드바이저](https://searchadvisor.naver.com) → 요청 → 웹 페이지 수집

미처리 항목이 3건 이상 쌓이면 CTO 리포트에 "색인 요청 밀림" 알림이 뜹니다.
