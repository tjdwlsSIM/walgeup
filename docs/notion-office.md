# 노션 사무실 (walgeupnote_company) 템플릿

`notion-logger` 가 이 템플릿으로 노션 페이지 **walgeupnote_company** 를 갱신한다.

## 갱신 방법

`mcp__notion__API-update-page-markdown` 로 **페이지 전체를 한 번에 덮어쓴다.**
블록 ID 를 추적하며 부분 수정하지 않는다 — 블록 단위로 관리하면 ID 대장을
따로 들고 있어야 하고, 그 대장이 틀어지는 순간 복구가 어렵다. 전체 덮어쓰기는
멱등이고, 실패해도 다음 실행이 알아서 맞춘다.

페이지 ID 는 코드에 박지 않는다. 매번 `API-post-search` 로 `walgeupnote_company`
를 찾는다.

## 갱신 시점
- morning / content / evening 모드 종료 시 (notion-logger 가 호출될 때마다)
- 즉 하루 2~3회. **실시간이 아니다.** 현황판 맨 위에 "마지막 갱신" 시각을 반드시
  적어 사용자가 언제 기준 정보인지 알 수 있게 한다

## 디자인 원칙 — 왜 사무실 모양인가

에이전트 12개가 각자 뭘 하는지는 표 한 장으로는 안 읽힌다. **부서와 좌석이라는
익숙한 은유**를 쓰면 "지금 누가 일하고 누가 쉬는지"가 훑기만 해도 들어온다.

다만 **은유가 정보를 이기면 안 된다.** 좌석 카드가 예뻐도 상태가 틀리면 쓸모없다.
아래 두 규칙이 디자인보다 우선한다.

1. **모르는 값은 `—`.** 추측해서 채우지 않는다. 현황판이 거짓말을 하면 안 보는 게 낫다
2. **상태는 이번 실행에서 관측한 것만.** 기억이나 짐작으로 🟢 를 달지 않는다

## 상태 표기 규칙

| 상태 | 뜻 | 판정 근거 |
|---|---|---|
| 🟢 근무 | 이번 실행에서 호출돼 정상 완료 | 해당 실행 로그 |
| ⚪ 대기 | 이번 실행에서 호출되지 않음 (정상) | 모드에 포함되지 않는 에이전트 |
| 🟡 반려 | 검수에서 FAIL 을 냈고 회송 진행 중 | 회송 카운트 |
| 🔴 정지 | HALT 유발 또는 FAIL 판정 | `logs/HALT`, `VERDICT: FAIL` |
| ☂ 한시 | 애드센스 승인 시 제거 예정 | adsense-audit 고정 |

```markdown
| evening | 매일 18시 이후 | {⏳ 예정} | {애드센스 72점} |

- 5분마다 밀린 작업을 확인하고, **한 틱에 하나씩** 실행한다
- 멈춤 신호 — `logs/STOP`(사용자) · `logs/HALT`(판단 필요) · 창 닫힘

- HALT 를 남긴 모드는 완료로 기록되지 않아 **재시작 시 다시 실행된다**
```

## 도면 생성 규칙 ★

도면은 **매 실행 아래 원본을 그대로 복사하고 대괄호 안의 표시만 바꾼다.**
칸 크기·간격·줄 길이를 손대지 마라 — 한 글자만 어긋나도 방이 찌그러진다.
(전체 줄 폭 54자 고정. 새 에이전트가 늘면 그때 재생성한다)

| 표시 | 뜻 |
|---|---|
| `[#]` | 앉아서 근무 — 이번 실행에서 호출돼 완료 |
| `[ ]` | 빈자리 — 호출되지 않음 |
| `[!]` | 정지 — HALT 유발 또는 FAIL |
| `[~]` | 재작성 중 — 검수 회송 진행 중 |

**도면 안에는 한글·이모지를 절대 넣지 마라.** 코드블록은 고정폭 폰트로 렌더링되는데
한글과 이모지는 폰트마다 1칸/2칸으로 달라져 정렬이 깨진다. 한글 부서명은 도면
바깥 범례 줄에 둔다. 아래 원본이 ASCII 전용인 이유가 이것이다.

```
+----------------------------------------------------+
| EXECUTIVE ROOM                                     |
```

**루프가 멈춰 있으면 도면 위에 소등 안내를 붙인다.** 도면은 "지금 일하는 중"이
아니라 **마지막 근무 시점의 스냅샷**이다. 이걸 안 적으면 새벽 4시에 페이지를 연
사람이 "지금 cto 가 일하고 있구나"로 읽는다.

## 렌더링 주의 — 실제로 겪은 함정 두 개

**① 인용 블록을 연달아 쓰면 하나로 합쳐진다.**
노션은 빈 줄 없이 이어진 `>` 줄을 **한 개의 인용 블록**으로 합친다. 좌석 카드를
전부 `>` 로만 만들면 부서 전체가 한 덩어리가 돼 카드 구분이 사라진다.
그래서 카드는 **굵은 이름 줄(일반 문단) + 인용 한 줄** 두 블록으로 만든다.
사이에 문단이 끼므로 인용이 합쳐지지 않는다.

```
**🟢 cto** · 총괄 오케스트레이터

> 마지막 근무 07-26 04:21 morning · 산출물 — morning 리포트
```

**② 표 셀 안의 `**굵게**` 는 렌더링되지 않는다.**
`| 국민연금 **상한** |` 은 별표가 그대로 보인다. 표 안에서는 강조를 쓰지 말고,
강조가 필요하면 표 밖 인용 블록으로 뺀다.

- 부서 제목은 `##`, 카드 이름은 `**굵게**` 로 고정한다. 계층이 흔들리면
  훑어보기가 안 된다
- 상태 이모지는 **이름 앞**에 붙인다. 줄 끝에 두면 이름 길이에 따라 위치가
  들쭉날쭉해져 세로로 훑을 수 없다
- **이모지는 정해진 것만 쓴다.** 상태(🟢⚪🟡🔴☂)와 부서(🏛🛡✍🔍🚀) 외에
  임의로 추가하지 않는다. 장식이 늘면 상태 이모지가 눈에 안 띈다
- 12명 전원을 **매번 다 적는다.** 근무하지 않은 에이전트를 생략하면
  "쉬는 중"과 "사라짐"이 구분되지 않는다

## 주의

- **수치를 추측해 채우지 마라.** 실제로 세거나 로그에서 읽은 값만 쓴다.
  모르는 값은 `—` 로 둔다
- 노션 갱신이 실패해도 **작업을 실패로 처리하지 마라.** `docs/agent-log.md` 가
  원본이다. 노션은 사본이다
- 페이지가 공유되지 않았으면(검색 결과 0건) 조용히 건너뛰고 안내만 출력한다
