# 노션 사무실 (walgeupnote_company) 템플릿

`notion-logger` 가 이 템플릿으로 노션 페이지 **walgeupnote_company** 를 갱신한다.

## 갱신 방법

`mcp__notion__API-update-page-markdown` 로 **페이지 전체를 한 번에 덮어쓴다.**
블록 ID 를 추적하며 부분 수정하지 않는다 — 블록 단위로 관리하면 ID 대장을
따로 들고 있어야 하고, 그 대장이 틀어지는 순간 복구가 어렵다. 전체 덮어쓰기는
멱등이고, 실패해도 다음 실행이 알아서 맞춘다.

페이지 ID 는 코드에 박지 않는다. 매번 `API-post-search` 로 `walgeupnote_company`
를 찾는다.

## 갱신 시점
- morning / evening / content 모드 종료 시 (notion-logger 가 호출될 때마다)
- 즉 하루 3~4회. **실시간이 아니다.** 현황판에 "마지막 갱신" 시각을 반드시 적어
  사용자가 언제 기준 정보인지 알 수 있게 한다

## 상태 표기 규칙

| 상태 | 뜻 | 판정 근거 |
|---|---|---|
| 🟢 근무 | 이번 실행에서 호출돼 정상 완료 | 해당 실행 로그 |
| ⚪ 대기 | 이번 실행에서 호출되지 않음 (정상) | 모드에 포함되지 않는 에이전트 |
| 🔴 정지 | HALT 유발 또는 FAIL 판정 | `logs/HALT`, VERDICT: FAIL |
| 🟡 반려 | 검수에서 FAIL 을 냈고 회송 진행 중 | 회송 카운트 |
| ☂ 한시 | 애드센스 승인 시 제거 예정 | adsense-audit 고정 |

## 템플릿 (이 구조를 유지하고 값만 바꿔 쓴다)

```markdown
# 🏢 월급노트 컴퍼니

> **루프 상태: {🟢 가동 중 | 🔴 정지 (HALT) | ⏸ 중지 (STOP)}**
> 마지막 갱신 {YYYY-MM-DD HH:MM} · 다음 예정 작업 {모드} {시각}
> {정지 상태면: 정지 사유 한 줄 + "해결 후 scripts\start.bat 으로 재시작"}

## 📊 오늘의 근무 현황 ({YYYY-MM-DD})

| 에이전트 | 부서 | 상태 | 마지막 근무 | 최근 산출물 |
|---|---|---|---|---|
| cto | 경영 | 🟢 근무 | 09:00 morning | 리포트 (계산기 PASS) |
| qa-calculator | 상시 감시 | 🟢 근무 | 09:00 | 14/14 PASS |
| law-monitor | 상시 감시 | 🟢 근무 | 09:02 | 변경 0 · 미확정 관찰 2 |
| planner | 콘텐츠 제작 | ⚪ 대기 | 07-24 15:00 | 「주제」 |
| researcher | 콘텐츠 제작 | ⚪ 대기 | 07-24 15:04 | 수치 12건 확보 |
| writer | 콘텐츠 제작 | ⚪ 대기 | 07-24 15:11 | 초안 1,840자 |
| editor | 콘텐츠 제작 | ⚪ 대기 | 07-24 15:19 | HTML 완성 |
| reviewer-quality | 품질 관리 | ⚪ 대기 | 07-24 15:24 | PASS |
| reviewer-facts | 품질 관리 | ⚪ 대기 | 07-24 15:24 | PASS |
| publisher | 발행 | ⚪ 대기 | 07-24 15:28 | 발행 완료 |
| notion-logger | 기록 | 🟢 근무 | 09:03 | 이 페이지 갱신 |
| adsense-audit | 한시 ☂ | ⚪ 대기 | 07-24 18:00 | 72/100 |

## 🔄 루프 운영

| 모드 | 예정 | 오늘 | 최근 결과 |
|---|---|---|---|
| morning | 매일 09시 | ✅ 완료 09:03 | 계산기 PASS · 법령 변경 없음 |
| content | 월·수·금 15시 | ⏳ 예정 | 07-24 발행 (회송 1회) |
| evening | 매일 18시 | ⏳ 예정 | 애드센스 72점 |

- 틱 간격 5분 · 밀린 작업은 자동 추격
- 멈춤 신호: `logs/STOP`(사용자) · `logs/HALT`(판단 필요) · 창 닫힘
- **HALT 는 3가지 경우에만** — qa FAIL / 3회 반려 에스컬레이션 / 법령 확정치 변경
```

## 주의

- **수치를 추측해 채우지 마라.** 실제로 세거나 로그에서 읽은 값만 쓴다.
  모르는 값은 `—` 로 둔다. 사무실 현황판이 거짓말을 하면 안 보는 게 낫다
- 노션 갱신이 실패해도 **작업을 실패로 처리하지 마라.** `docs/agent-log.md` 가
  원본이다. 노션은 사본이다
- 페이지가 공유되지 않았으면(검색 결과 0건) 조용히 건너뛰고 안내만 출력한다
