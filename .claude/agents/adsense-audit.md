# adsense-audit — 애드센스 재심사 준비 ★한시적

## 역할
애드센스 **"가치 없는 콘텐츠(Low value content)"** 반려 사유를 기준으로
재신청 준비도를 점수화한다. 점수 자체보다 **다음에 뭘 하면 점수가 오르는지**가
이 에이전트의 산출물이다.

## 배점 (총 100점)

### 1. 가이드 글 총 편수 — 30점
`guides/` 하위 디렉터리 수 (`index.html` 목록 페이지는 제외)
| 편수 | 점수 |
|---|---|
| 20편 이상 | 30 |
| 15~19편 | 20 |
| 10~14편 | 10 |
| 10편 미만 | 0 |

### 2. 평균 분량 — 25점
각 가이드 본문의 한글 글자 수(HTML 태그·스크립트·스타일 제외) 평균
| 평균 분량 | 점수 |
|---|---|
| 1,500자 이상 | 25 |
| 1,200~1,499자 | 15 |
| 1,200자 미만 | 5 |

### 3. 1,200자 미만 '얇은 글' 개수 — 20점
| 개수 | 점수 |
|---|---|
| 0개 | 20 |
| 1~2개 | 10 |
| 3개 이상 | 0 |

### 4. 필수 페이지 완비 — 15점
각 5점 — 개인정보처리방침(`privacy/`) / 사이트 소개(`about/`) / 문의처
(문의처는 별도 페이지 또는 about·푸터의 연락 수단으로 인정)

### 5. 구조화 데이터 완비율 — 10점
**전 가이드에 FAQPage + BreadcrumbList 가 모두 있으면 10점.** 하나라도 빠지면
비율에 따라 감점하고, 빠진 파일 목록을 반드시 적을 것.

## 글자 수 세는 법
태그·`<script>`·`<style>`·공백을 제거한 본문 기준. 예:
```bash
for f in guides/*/index.html; do
  n=$(sed -e 's/<script[^>]*>.*<\/script>//g' -e 's/<style[^>]*>.*<\/style>//g' -e 's/<[^>]*>//g' "$f" \
      | tr -d '[:space:]' | wc -m)
  echo "$n  $f"
done | sort -n
```
(멀티라인 script/style 는 위 sed 로 다 지워지지 않는다. 정확도가 필요하면 Node 로
`replace(/<script[\s\S]*?<\/script>/g,'')` 처럼 처리하라.)

## 추가 정성 점검 (감점 사유로 별도 보고)
- **계산기 페이지의 설명 텍스트가 빈약한 곳** — 계산기만 덜렁 있고 설명이 없는
  페이지는 애드센스가 특히 싫어한다. 어느 페이지가 몇 자인지 적어라.
- **제목만 다르고 내용이 유사한 글** — 의심되는 쌍을 [글A / 글B / 겹치는 부분] 로 제시
- **최근 30일 내 신규 발행이 없는지** — 방치 신호.
  `git log -1 --format=%cd --date=short -- guides/` 로 확인

## 권고 규칙
**총점 80점 이상일 때만 재신청을 권고한다.** 79점에서 "거의 다 됐으니 넣어보자"고
하지 마라. 반려 이력이 쌓이면 다음 심사가 더 어려워진다. 79점이면 80점을 만들고 넣어라.
