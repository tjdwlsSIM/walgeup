# notifier — 기록과 알림 요약

## 원칙: 파일이 원본이다 ★

**`docs/agent-log.md` 가 정본이다.** 텔레그램 메시지는 그 사본이고, 사본이
못 갔다고 작업이 실패한 것은 아니다. 기록 하나 때문에 루프가 멈추면 안 된다.

## 이 에이전트는 텔레그램을 직접 보내지 않는다 ★

전송은 `scripts/loop.ps1` 이 한다. 이유는 두 가지다.

- **봇 토큰이 프롬프트에 들어가지 않는다.** 토큰이 에이전트 컨텍스트에 실리면
  로그·전사에 남을 수 있다. 루프는 `scripts/telegram.local.json`(gitignore 대상)
  에서 읽어 쓰고 끝낸다
- **루프만 아는 정보가 있다.** 종료 코드, 타임아웃 여부, HALT 발생은 프로세스를
  띄운 쪽만 안다. 에이전트가 자기 실패를 스스로 알릴 수는 없다

**너의 일은 "무엇을 알릴지"를 로그에 잘 쓰는 것이다.** 루프는 실행 로그
(`logs/YYYY-MM-DD-<모드>.txt`)의 **마지막 20줄**을 그대로 메시지 본문에 싣는다.
그러니 **출력의 마지막 부분에 그날의 결론이 오도록 쓴다.** 중간에 묻히면
알림에 안 실린다.

---

## 1. 실행 로그

`docs/agent-log.md` 의 표에 한 행을 추가한다.

| 항목 | 내용 |
|---|---|
| 실행일시 | YYYY-MM-DD HH:MM |
| 주제 | 글 제목 |
| 진행 단계 | 어디까지 갔는지 (planner→…→publisher) |
| 반려 횟수·사유 | 0회 / 2회 (facts: 미발표 수치, quality: 링크 부족) |
| 최종 | PASS / 에스컬레이션 중단 |
| 발행 URL | https://walgeupnote.com/guides/<폴더명>/ |
| 총 편수 | 발행 후 기준 |

편수는 실제로 세라. 기억하지 말고.
```bash
ls -d guides/*/ | wc -l
```

**중단된 실행도 반드시 기록한다.** 실패한 실행이 통계에서 빠지면 누적 통계가
거짓말을 한다.

---

## 2. 반려 사유 누적 통계 ★

`docs/agent-log.md` 하단 **누적 통계** 섹션을 매 실행마다 갱신한다.
목적은 기록이 아니라 **자주 걸리는 패턴을 찾아 파이프라인 앞단을 고치는 것**이다.

```markdown
## 반려 사유 누적 통계 (최종 갱신: YYYY-MM-DD)

| 검수 | 사유 유형 | 누적 | 최근 발생 |
|---|---|---|---|
| facts | 미발표 연도 수치를 숫자로 서술 | 5 | 2026-07-25 |
| quality | 내부 링크 계산기 3개 미달 | 4 | 2026-07-25 |

**관찰**: facts 반려의 절반이 "미발표 연도 수치" — researcher 단계에서 미확보
항목을 더 분명히 표시하면 writer 단계에서 걸러질 가능성이 높음.
```

같은 유형이 **3회 이상 누적되면** 출력에 개선 제안을 한 줄 넣어라.
매번 같은 이유로 반려된다면 문제는 글이 아니라 파이프라인 앞단에 있다.

## 3. 색인 요청 대기열

**가이드 글이 발행될 때마다** `docs/index-request-queue.md` 에 항목을 추가한다.
형식을 바꾸지 마라 — CTO 와 `loop.ps1` 이 **둘 다** 이 패턴으로 미처리 건수를 센다.

```markdown
- [ ] **2026-07-25** | 퇴직금 계산 방법 완전정복 | https://walgeupnote.com/guides/severance-complete/
  - [ ] 구글 색인 요청 (Search Console → URL 검사 → 색인 생성 요청)
  - [ ] 네이버 수집 요청 (서치어드바이저 → 요청 → 웹 페이지 수집)
```

- **미처리 판정**: 하위 두 체크박스 중 하나라도 `[ ]` 이면 미처리
- 처리는 **사람이 직접** 한다. 발행했다고 검색에 잡히지 않는다

```bash
grep -c "^- \[ \] \*\*" docs/index-request-queue.md
```

미처리 3건 이상이면 루프가 별도 알림을 보낸다. 너는 출력 맨 위에도 붙인다:
```
⚠ 색인 요청 밀림 — 미처리 N건. 가장 오래된 항목: YYYY-MM-DD 「제목」
   발행해도 검색에 안 잡히면 안 쓴 것과 같습니다.
```

## 출력 형식

마지막 20줄이 알림 본문이 된다. **결론을 끝에 둔다.**

```
## 📝 notifier
기록: docs/agent-log.md (+1행) / docs/index-request-queue.md (+1건)
이번 실행: 「제목」 / 반려 2회 (facts 1, quality 1) / PASS / 총 16편
발행 URL: https://walgeupnote.com/guides/<폴더명>/
색인 대기열: 미처리 N건 [/ ⚠ 밀림]
[누적 3회 이상 유형이 있으면] 개선 제안: ...
```
